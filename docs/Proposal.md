# 结课项目规划说明（Proposal）

**课程**：人工智能实践
**方向**：多智能体构建 + 提示词自动优化
**题目**：基于多智能体与提示词自动优化的工业视觉质检系统——以螺丝/螺母为例
**演示平台**：AUP Learning Cloud（云端 JupyterHub / 算力）
**开源**：GitHub / Gitee

---

## 1. 选题背景与意义

工业质检是人工智能落地最成熟的场景之一。但中小企业在落地时普遍面临三道坎：

1. **缺数据**：没有公开的螺丝/螺母缺陷数据集，人工标注成本高。
2. **VLM 直接检测不稳**：视觉大模型可以理解整幅图像的语义，却给不出多长算划痕、多大算缺料这类稳定的几何判据，直接端到端检测误判率高。
3. **提示词难调**：让大模型按规则判定缺陷，规则阈值常凭经验拍脑袋，换一批光照或工件就失准，且缺乏系统化的调优手段。

本项目用**多智能体协作 + 提示词自动优化闭环**回应这三个问题：数据用程序化合成（自带真值），视觉模型只做「眼睛」（经典 CV 感知层），语义分析与分级交给智能体，判据阈值由反思 Agent 基于标注样本自动校准。

---

## 2. 问题定义

- **输入**：单张螺丝或螺母的灰度/彩色图像。
- **输出**：
  - 缺陷类型：`scratch`(划痕) / `bent`(变形，仅螺丝) / `missing`(缺料) / `rust`(锈蚀) / `color`(色差) / `none`(无缺陷)；
  - 严重程度：`mild` / `moderate` / `critical`；
  - 产线处置建议（SOP）：报废 / 返修 / 放行。
- **优化目标**：在**零过杀**（不误杀良品）硬约束下，把漏检压到最低，并尽量提升类型与分级准确率。

---

## 3. 技术方案

### 3.1 多智能体架构

| 智能体 | 职责 |
|---|---|
| 感知层（经典 CV） | 模板差分 + 连通域 + 轮廓几何，输出结构化特征（异常分、可疑区域数/面积/长宽比、几何畸变、面积偏差） |
| 缺陷分析 Agent | 按提示词 RULES 段中的判据树，判定缺陷类型与严重度 |
| 分级决策 Agent | 把缺陷映射到产线 SOP 处置，带严重度硬约束兜底 |
| 反思优化 Agent | 从 dev 集误判中归因到具体判据，反推边界、改写提示词、keep-best 回灌 |

### 3.2 提示词自动优化闭环

1. 在 **dev 集**上评测当前提示词，收集误判样本（漏检 / 过杀 / 类型错 / 分级错）。
2. 反思 Agent 对误判**投票归因**，定位「哪条判据」导致错误。
3. 用 dev 集标注样本**反推该判据的最优边界**（良品特征上界作 floor、缺陷特征下界作上限，AutoPrompt 式）。
4. 改写提示词 RULES 段，复评 dev；**仅当指标不更差才接受**（keep-best），保证曲线单调。
5. 最终指标只在独立 **test 集**汇报，避免数据泄露。

### 3.3 对照实验（证明价值）

- **基线1**：单模型·异常分阈值（仅良/不良二分类，无类型/分级），阈值在 dev 选、test 报。
- **基线2**：多智能体·人工经验提示词（未优化），@test。
- **本方案**：多智能体·提示词自动优化，@test。

## 4. 数据方案

采用**程序化合成数据**（`qc_demo/synthetic_data.py`）：
- 夹具定位（工件朝向固定）便于模板对齐；
- 覆盖螺丝的 scratch/bent/missing/rust 与螺母的 scratch/color/missing/rust；
- 引入机加工纹理（良品也有的歧义源）与光照波动，提升难度；
- 每件自带 ground truth，开箱即跑，不依赖任何外部数据。

> 真实数据迁移路径（MVTec AD 的 screw/nut）见 README 第 7 节：只需替换数据来源与感知层对齐，Agent 与优化闭环原样复用。
